# ManageCrisis: Information System for Crisis Understanding and Monitoring

## Overview
[cite_start]Developed for **Université Toulouse 1 Capitole** [cite: 1, 5][cite_start], **ManageCrisis** is a web-based platform designed to enhance crisis management in **Toulouse, France**[cite: 27, 39]. [cite_start]It provides a potential solution for government officials and crisis managers to consolidate data, facilitate communication, and optimize resource allocation[cite: 36, 37].

## Key Features
* [cite_start]**Interactive Map**: Locates all components affected by a crisis and displays available actors[cite: 163, 205].
* [cite_start]**Crisis Scenarios**: Dedicated pages for both past events and current ongoing crises[cite: 161, 174, 175].
* [cite_start]**Analytical Dashboards**: Visualizes the evolution of damage severity over time and risk frequency[cite: 154, 155, 157].
* [cite_start]**Resource Allocation**: Bar charts showing the distribution of actors across various affected locations[cite: 285, 287].
* [cite_start]**Citizen Awareness**: A specific portal to inform the public on how to prepare for natural crises[cite: 160].

## Tech Stack
* [cite_start]**Front-end**: HTML, CSS, JavaScript, Bootstrap, and jQuery[cite: 130, 135, 136, 137, 139].
* [cite_start]**Back-end**: PHP using XAMPP server[cite: 130, 131].
* [cite_start]**Database**: MySQL managed via phpMyAdmin[cite: 131, 141].
* [cite_start]**Data Processing & ML**: Python (Pandas), Scikit-learn (Linear Regression), Matplotlib, and Seaborn[cite: 148, 153, 157].
