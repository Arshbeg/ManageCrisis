# ManageCrisis: Information System for Crisis Understanding and Monitoring

## Overview
Developed for **Université Toulouse 1 Capitole**, **ManageCrisis** is a web-based platform designed to enhance crisis management in **Toulouse, France**. It provides a potential solution for government officials and crisis managers to consolidate data, facilitate communication, and optimize resource allocation.

## Key Features
**Interactive Map**: Locates all components affected by a crisis and displays available actors.
**Crisis Scenarios**: Dedicated pages for both past events and current ongoing crises.
**Analytical Dashboards**: Visualizes the evolution of damage severity over time and risk frequency.
**Resource Allocation**: Bar charts showing the distribution of actors across various affected locations.
**Citizen Awareness**: A specific portal to inform the public on how to prepare for natural crises.

## Tech Stack
**Front-end**: HTML, CSS, JavaScript, Bootstrap, and jQuery.
**Back-end**: PHP using XAMPP server.
**Database**: MySQL managed via phpMyAdmin.
**Data Processing & ML**: Python (Pandas), Scikit-learn (Linear Regression), Matplotlib, and Seaborn.
